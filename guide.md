# Kubernetes Observability Platform — Project Roadmap

## Phase 1 — Kubernetes Environment

- [ ] Prepare Minikube.
- [ ] Install Helm.
- [ ] Understand Kubernetes namespaces.
- [ ] Verify cluster health.

## Phase 2 — Deploy Observability Stack

- [ ] Install Prometheus.
- [ ] Install Grafana.
- [ ] Install Alertmanager.
- [ ] Configure Node Exporter and kube-state-metrics.

## Phase 3 — Deploy Sample Application

- [ ] Build an Express application.
- [ ] Expose application metrics.
- [ ] Create a Docker image.
- [ ] Deploy the application on Kubernetes.

## Phase 4 — Metrics Collection

- [ ] Configure Prometheus scraping.
- [ ] Understand Prometheus scrape targets.
- [ ] Explore PromQL.
- [ ] Monitor application and infrastructure metrics.

## Phase 5 — Dashboards and Alerting

- [ ] Create Grafana dashboards.
- [ ] Configure CPU and memory alerts.
- [ ] Configure application error-rate alerts.
- [ ] Test Alertmanager notifications.

## Phase 6 — SRE Practices

- [ ] Define Service Level Indicators (SLIs) and Service Level Objectives (SLOs).
- [ ] Calculate error budgets.
- [ ] Simulate application failures.
- [ ] Perform incident investigation.

## Phase 7 — Production-Style Delivery

- [ ] Add GitHub Actions CI/CD.
- [ ] Store Kubernetes manifests in Git.
- [ ] Write operational runbooks.
- [ ] Document architecture and incidents.
